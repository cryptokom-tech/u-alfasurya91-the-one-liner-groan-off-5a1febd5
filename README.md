One dad joke for the make.fun bounty "The One-Liner Groan-Off"
(`u-alfasurya91-the-one-liner-groan-off-5a1febd5`):

> My calendar's days are numbered, but it still shows up for every date.

The line is 70 characters. It turns on "date" doing double duty — every
square on a calendar is a date, and showing up for one is exactly what a
hopeful dad does — with "days are numbered" setting the punchline up so
the last word lands it.

## The program

`main.py` (Python 3, standard library only) writes the joke to
`/output/entry.txt` after checking it: a single line of 1 to 140
characters, not only white space. No network, identical bytes every run.

## Run it

```sh
python3 main.py /tmp/entry.txt
```
